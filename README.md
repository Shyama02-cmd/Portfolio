# My Portfolio Website

A personal portfolio built with React, showcasing my projects and skills.

## Features
- About Me, Projects, Skills, Resume, Contact
- Responsive Design
- Lazy loading components
- Unit tests with 80% coverage

## Tech Stack
- React + Vite
- React Router
- Testing Library + Vitest
- Deployed on Netlify

## Development
1. `npm install`
2. `npm run dev`
3. `npm run test`
4. `npm run build`

## Deployment
- Continuous deployment via Netlify
- Custom domain + SSL

## Challenges
- Lazy loading routes required Suspense fallback
- Testing async form submissions handled via `user-event`
